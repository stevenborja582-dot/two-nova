# Two-Nova

Asistente de escritorio para Windows: una isla en la pantalla que vigila a Claude Code (permitir o negar con un clic, avisos al terminar) y un panel donde conversas con 5 personalidades, cada una con su voz.

Autor: S1even
Estado: versión 0.3.1 (isla que se abre al pasar el mouse, con tablero de apps, panel con Inicio/Conexiones/Apariencia, voces y personalidades, cerebro con la API de Claude). Ver `INSTALAR.md`.
Plan completo: `replica/s1even.md` y `replica/architecture.md`.
